# Automated workflow in Fiji ImageJ for batch analysis of confocal imaging data to quantify protein colocalization using Manders coefficient
The workflow encompasses image conversion, refinement, substack creation, and final colocalization analysis using the BIOP JACoP plugin in Fiji (ImageJ). The detailed protocol can be found at Aditya, V., Tambe V., and Yue, W., Development of novel automated workflow in Fiji ImageJ for batch analysis of confocal imaging data to quantify protein colocalization using Manders coefficient, Bio-Protocol, 2025, 15(7): e5285, PMCID: PMC11986846
